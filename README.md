# Webaverse Character Studio
An open, collaborative and evolving 3D avatar studio for the open metaverse.

# Quick Start
```bash
# Clone the repo and change directory into it
git clone https://github.com/webaverse-studios/CharacterCreator
cd CharacterCreator

# Install dependencies with legacy peer deps flag to ignore React errors
npm install --legacy-peer-deps
npm run dev

# Or use yarn
yarn install
yarn run dev
```

## PWA Support

The app is configured as a Progressive Web App. You can install it on supported browsers and it will work offline after the first load.
